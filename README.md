# BR Imported — landing page

Landing page da BR Imported (Av. Dr. Maurício Cardoso, 1230, sala 1200, Novo Hamburgo/RS).

- HTML estático, sem build: `index.html` + `img/`
- GSAP (ScrollTrigger, SplitText, Flip), Lenis e Three.js via CDN
- Deploy automático na Vercel a cada push na `main`

Para rodar local: `npx serve .`

## Créditos
Modelo 3D "Apple iPhone 15 Pro Max Black" por [polyman](https://sketchfab.com/Polyman_3D), licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Convertido de Draco para malha quantizada (KHR_mesh_quantization) com glTF-Transform.
